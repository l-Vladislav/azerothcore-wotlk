# Russian text conventions for familiar names / descriptions

Rules and translation table for all Russian text in `Spell_custom.csv`, `creature_template_locale`, `item_template_locale` for the familiar gacha system.

## Hard rules

1. **No English in ruRU strings.** Don't leave stat abbreviations (`Int`, `Sta`, `Holy res`) in the Russian description — translate or use the abbreviated Russian forms below. Empirically caught 2026-05-30 in `102059` summon desc; user reported "часть на английском" — the description had «+5% урон тенью / Int / Shadow res; -10 Holy res, -5% Sta».
2. **Use ASCII punctuation only.** No `U+2212` minus (use `-`), no `U+2014` em-dash (use `:` or `-`), no smart quotes. The 3.3.5a client font lacks those glyphs and renders boxes — see [[client-glyph-set]] in main memory.
3. **Keep descriptions tight.** Pet tooltip + buff bar tooltip are narrow; long lines wrap and look messy. One sentence per buff, comma-separated effects.

## Description format conventions (current — 2026-05-30, owner-confirmed)

**COMPACT genitive tokens.** Each effect → `<+/-><N>% <stat in genitive>` (flat
stats: `<+/-><N> <gen>`, no `%`). Full stat names, **no abbreviations** («шанса
критического удара», not «крит»), **no English** («силы атаки», not «AP»). ASCII `-`/`+`.

**Placement (owner-confirmed split):**
- **Buff aura (103xxx) tooltip = buffs only** (comma-separated). `+2% выносливости`
- **Debuff aura (104xxx) tooltip = debuffs only**. `-1% духа`
- **Summon spell** (Companions menu) = `Призывает <accusative>. <FULL list>` — buffs+debuffs.
- **Scroll/cage item** = `Клетка с: <nominative>` (name) + description `Обучает призывать
  фамильяра: <name>. <FULL list>`.

FULL list = buffs `, `-joined, then `; `, then debuffs `, `-joined:
`+5% брони, +5% выносливости, +5% уворота; -10% силы атаки, -5% шанса критического удара`
Clean Common: `+1% брони`. Flawed: `+1% брони; -1% скорости передвижения`.
Flat resist: `+3 сопротивления всем школам магии` (no `%`).

Generated by `scripts/familiar-gen-sql.ps1` from effect `code`s via the genitive
`StatRu` map — do not hand-write; add new aura codes to the map.

## Russian grammar — animate accusative for pet names

The pet name in «Призывает <X>» needs animate-accusative case, not nominative:

| Nominative (creature row) | Accusative (in «Призывает …») |
|---|---|
| Каменный Кремешок | Каменного Кремешка |
| Треснувший Кремешок | Треснувшего Кремешка |
| Грозовой Орёл | Грозового Орла |
| Рыжий Лисёнок | Рыжего Лисёнка |
| Волчонок-Страж | Волчонка-Стража |
| Лик Сумрака | Лик Сумрака (already inanimate-style, no change) |

For inanimate-feeling names (some abstract Epic names like «Лик Сумрака»), the accusative often coincides with nominative — leave as-is. For animal/diminutive names, decline.

## Both `Description` AND `AuraDescription` must be set

`Description_Lang_ruRU` (row[176]) shows in the spellbook tooltip. `AuraDescription_Lang_ruRU` (row[193]) shows in the buff/debuff bar tooltip. Set BOTH — `scripts/familiar-gen-sql.ps1 -Csv` does this automatically. Don't trust that one falls back to the other; the client reads them independently.
