# Охотничий контур Немезиды — дизайн (финал 2026-06-12, PTR)

Единый документ по игровому циклу: **враги рождаются → охотник растёт → поручения
дают монету и репутацию → монета покупает сумки → фамильяры**. Технические детали —
в [nemesis_system.md](nemesis_system.md); фамильяры/сумки — в
[../familiars/](../familiars/familiar_gacha_chests_plan.md).

Статус: реализовано, протестировано владельцем in-game на PTR 2026-06-11/12.
Клиентский WDBX-мерж (Item.dbc 12 строк, ItemExtendedCost 2 строки) выполнен.

## 1. Откуда берутся немезиды

| Источник | Триггер | Стартовый ранг | Запись |
|---|---|---|---|
| **Классика** | моб убил игрока (фильтры уровня/ранга/кулдауны) | 1 + бонус охотника **жертвы** | БД (`character_nemesis`) |
| **Эмбиент** | тик 300–600с (рандом); зона с реальным игроком ниже 50% от `MaxPerZone` → 1 рождение/зону | 1 + бонус лучшего охотника **зоны** | БД, `target_guid=0` |
| **Данж** | 3% на спавн трэша/элитки в инстансе (свип при входе + поздние гриды) | ролл 50/30/15/4/1 + бонус лучшего охотника **инстанса** | временная (ObjectGuid, умирает с инстансом) |
| **Гарантия поручения** | принятие мирового поручения без подходящей цели | 1 + бонус принявшего | БД, **без анонса** |

- Эмбиент: 10% (`RankUpChance`) вместо рождения — ранк-ап случайной живой немезиды
  зоны; 25% (`EliteChance`) рождение предпочитает **элитку** (цели для «Заморской охоты»).
- Rare — только через классику (их строки привязаны к игроку-цели).
- Боссы, цивилы, петы, рейды (по умолчанию) — исключены везде.
- **Аддон-пуш**: рождения/ранк-апы эмбиента и данжа шлют `UPSERT_VALIDATED`
  игрокам зоны/инстанса мгновенно (чат-триггеры — только подстраховка).

## 2. Ранг охотника масштабирует мир

Ранг Ковенанта (1–5: Послушник → Охотник → Следопыт → Ветеран Охоты → Легенда
Охоты) даёт бонус **стартового** ранга новых немезид: 1–2 → +0, 3–4 → +1, 5 → +2
(`HunterRankScaling.Enable`). Тот же бонус увеличивает квоту зачистки (см. §3).

## 3. Особое поручение (трактирщик, рядом с доской)

- **Назначается, не выбирается**: ролл guid⊕день → 1 из 3. Меню: «Сегодня есть
  лишь одно дело — "…"» + одна кнопка. (PTR-тумблеры `FreeChoice`/`NoDailyLimit`
  снимают это для тестов; в проде = 0.)
- **1 выполнение в день**; бросить можно, перевзять — тот же тип.
- **Именованная цель**: принятие выбирает конкретного врага в пределах
  **±3 уровней игрока** (`TargetLevelBand`): существующего (живого, в
  загруженном гриде), иначе **тихо рождает**; нет кандидата в ±3 — рождает
  ближайшего по уровню (принятие не отказывает). Для зачистки — конкретный
  данж. Цель называется с **зоной по-русски** в чате/меню/аддоне и пушится
  принявшему в аддон сразу при принятии.
- **Фильтры цели** (2026-06-12): обычная фаза (не ивентовая), не выше 50
  ярдов над рельефом (летающие некрополи/WMO), атакуема принявшим
  (стражники одной фракции исключаются). Те же фильтры чистят эмбиент.
- **Зачёт мировых поручений — ТОЛЬКО именованная цель**; промахи тихие,
  задание висит до выполнения. Зачёт — каждому получателю награды за килл
  (группа работает).
- Награда: **1 «Монета авантюриста»** почтой (RP-вариации 4×3) + **репутация
  100 + ранг охотника** (`NemesisRep.SpecialTask{Bonus,PerRank}`).

| Тип | RP-имя | Условие | Лимит |
|---|---|---|---|
| SPEED | Горячий след | именованная **обычная** (не элита) цель ±3 уровня на **твоём континенте** (фиксируется при принятии: ВК/Калимдор/Запределье/Нордскол) | **2 ч** («Осталось: 1 ч 54 мин»; просрочка → авто-сброс с перевзятием) |
| CONTINENT | Заморская охота | именованная **элитная** (элита/рара-элита) цель ±3 уровня на **противоположном классическом** континенте; взять — только в ВК/Калимдоре | день |
| DUNGEON | Охота во тьме | **конкретный данж**: ролл из LFGDungeons по уровню **±10**, только 5-ппл (`map_type==1`, рейды исключены жёстко), TBC с 62 / Нордскол с 72; убить **не менее 3/4/5** (по рангу охотника) данж-немезид в нём; прогресс в чате и аддоне («Повержено: 1 из 3») | день |

## 4. Экономика

**Монета** (110150, иконка inv_misc_coin_17): только за поручение (1/день в проде).
**Репутация** (пороги PTR: 1000/5000/16000/40000):

| Источник | Очки |
|---|---|
| убийство немезиды | 1×ранг цели (gray-gated) |
| контракт доски | 10 + 5×ранг цели |
| особое поручение | **100 + ранг охотника** |

Дефолты кода/conf.dist выровнены под эту шкалу (2026-06-12). Конвертации
жетоны↔монеты нет.

## 6. Анонсы и локализация

- Слово «немезида» **убрано из всех строк** (RP: добыча/грозный враг/чудовища).
- Данж: одно «Вы чувствуете присутствие сильного врага…» (дебаунс 120с/инстанс);
  убийства в данже — тихие. Эмбиент — в зону; классика — мировой.
- **ruRU-имена зон/данжей**: серверный том получил `AreaTable.dbc` + `Map.dbc`
  из ruRU-клиента владельца (эталоны в `.claude/dbc/ruRU-source/`; community
  client-data был enUS-only). `GetZoneName` читает ruRU-слот; имена данжей —
  из Map.dbc. Время — человеческое («2 ч», «1 ч 54 мин»).
- Аддон: панель поручения (эпик-стиль, отсчёт ч/мин, прогресс зачистки),
  данж-немезиды в зоне-табе (матч по mapId через `V2:DUNGEON`).

## 8. Уроки сессии (операционные)

- Вчерашний «шторм» (краши мир+MySQL+auth) был **OOM в WSL2** (лайв-мир exit 137),
  не кодом. Не гонять сборки во время игровых сессий при поднятом лайве.
- Залип «Соединение установлено» после рестартов БД — протухший async-канал auth;
  лечится 2-3 повторными попытками логина (ядро переподключается само).
- Клиентский WDB переписывается из памяти при выходе — чистить **только при
  закрытом клиенте**.
