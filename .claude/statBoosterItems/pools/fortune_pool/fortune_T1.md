# Fortune Pool T1 — Малый символ удачи (100013)

**iLvl range: 1-25 | Skill: 25 | Inscription**

> **SYNC:** When editing this file, also update `SB.DB.EnchantNames[id]` in
> `modules/StatBooster/ClientAddon/StatBoosterUI/EnchantDB.lua` with Russian names
> for any new enchant IDs. Pool structure syncs from server automatically.

> **NOTE: RoleMask is NOT used in pool selection.** `BoostItemFromPool()` passes
> `roleMask=0`, so ALL enchants can roll for ANY class. The only active filters are:
> **iLvl range**, **ItemClassFilter** (weapon/armor/shield), and **ItemTypeMask** (slot bitmask).
> RoleMask column exists in DB but is ignored for Fortune scrolls.

### Why these spells:
- **18764 (+3 HoT)** — New effect category (periodic heal). Weak but useful at low level. Works on any gear.
- **12896 (+5 retribution)** — Damage shield alternative to Thorns 3. Slightly stronger. Armor-only.
- **34343 (+5 melee dmg)** — Flat bonus melee damage. Unlike weapon procs, works from ANY slot.
- **9784 (+7 melee dmg)** — Stronger version. Both give phys players non-weapon options.
- **21592 (+3 HP5)** — Weaker HP5 than +6 (90010). Adds combat regen variety. Same aura type as existing 21348.
- **18673 (+2 resist)** — Weaker all-resist than +6 (90008). Adds another defensive option.
