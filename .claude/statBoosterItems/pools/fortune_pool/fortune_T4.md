# Fortune Pool T4 — Великий символ удачи (100016)

**iLvl range: 66-92 | Skill: 250 | Inscription**

> **SYNC:** When editing this file, also update `SB.DB.EnchantNames[id]` in
> `modules/StatBooster/ClientAddon/StatBoosterUI/EnchantDB.lua` with Russian names
> for any new enchant IDs. Pool structure syncs from server automatically.

> **NOTE: RoleMask is NOT used in pool selection.** `BoostItemFromPool()` passes
> `roleMask=0`, so ALL enchants can roll for ANY class. The only active filters are:
> **iLvl range**, **ItemClassFilter** (weapon/armor/shield), and **ItemTypeMask** (slot bitmask).

## Slot assignment rules (consistent across all tiers)
- **Speed**: No Head, No Shield
- **Water Walk**: Neck, Feet
- **Swim Speed**: Feet, Hands
- **Mount Speed**: Neck, Waist, Legs, Feet, Wrists, Trinket, Back, 2H
- **Stealth Detect**: Head, Wrists
- **Rep Gain**: Finger, Trinket, Back
- **Feather Fall**: Wrists, Back
- **Thorns**: Shoulder, Legs, Wrists, Hands, Back, Shield (armor only)
- **Threat+**: No Neck, No Shield
- **AP**: No Head, No Neck
- **Threat-**: No Neck, Trinket, Back, Shield
- **CC Resist**: All armor except Neck, Shield
- **Resist/HP5**: Armor + Shield only (no weapons)
- **Weapons**: procs + AP/SP/MP5 only, no defensive/utility
