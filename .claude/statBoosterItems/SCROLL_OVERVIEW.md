# StatBooster Scrolls — Complete Overview

## How It Works

1. Player crafts a scroll via profession recipe
2. Uses scroll on equipment → applies random enchant from the scroll's pool
3. Enchant is permanent, persists through death
4. Attribute Recalibrator re-rolls within the **same pool and tier**
5. Each item can only have one StatBoost enchant

**Gear types:** Weapon = melee/ranged weapons, Armor = all non-shield armor, Shield = shields only, Any = all equipment

# Technical Details

## Enchant Slot
- Uses `PROP_ENCHANTMENT_SLOT_4` (slot 11) exclusively
- Core `Item.cpp` patched: `SetItemRandomProperties()` loop stops before slot 4
- No conflicts with player enchants, gems, or random properties

## Server-Side
- Custom enchant IDs: 90001-90049 (Fortune), 91001-91241 (stat copies with `##SB##` tag)
- `spellitemenchantment_dbc` table: 241 server-side DBC entries for 91xxx IDs
- `statbooster_enchant_template`: pool assignments, iLvl ranges, roles, class filters
- Enchant pool cache loaded at server startup
- `OnPlayerResurrect` hook re-applies PROP4 equip-spell auras lost on death
- Duplicate aura fix: unequip checks if another item provides the same spell

## Client-Side
- `SpellItemEnchantment_custom.csv` in MPQ: 288 entries with `##SB##` prefix
- Russian descriptions in `Name_Lang_zhTW` column (ruRU client quirk)
- Addon `StatBoostTooltip` strips `##SB##`, recolors yellow, detects duplicates (gray)

## Reroll (Attribute Recalibrator — Item 41605)
- Cached `enchantId -> poolGroup` lookup (no DB query per use)
- Re-rolls within the same pool
- Uses item's actual iLvl for enchant selection
