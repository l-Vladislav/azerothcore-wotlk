# Каталог перков предметов (mod-item-talents)

Табличная версия с иконками клиента и значениями по качествам: PERK_CATALOG.md.

Статус: ряды 1-4 — реализованы (сид `item_talent_def`, v1 разрешает выбор
в рядах 1-2); ряд 5 «Пробуждение» — ДИЗАЙН, фаза 2 (вместе с легендарной
ступенью GA, только для базовых эпиков).

Обозначения: N = ceil(коэф x ilvl), минимум 1. В скобках — значения на
ilvl 60 / ilvl 200 для чувства масштаба. Все цифры — заготовки под тюнинг.

## Роллы и качество (2026-07-06)

Каждый ряд имеет МЕНЮ вариантов (ниже), предмет при получении роллит
**3 случайных** (лениво, при первом обращении; хранится по GUID). Качество
каждого слота: Обычный x1.0 (70%) / Отличный x1.25 (25%) / Совершенный
x1.5 (5%) — множитель значения, цвет имени в аддоне белый/зелёный/фиолет.
Каждая ступень качества даёт МИНИМУМ +1 (решение 2026-07-06):
`значение(q) = max(значение(q-1) + 1, ceil(база x множитель))`.
Исключение: DURA_SAVE (износ) - ровные ступени 50/65/80 («чтобы выглядело
ровно», на геймплей влияет слабо).

## Ряд 5 «Пробуждение» — уникальные проки (фаза 2, дизайн)

Общие правила:
- Как и в других рядах — **выбор 1 из 3**, по набору на пул; у ОРУЖИЯ ряд 5
  подкласс-специфичный (решение 2026-07-06): мечи/топоры/булавы/древковое/
  кинжалы/кастеты и луки-арбалеты/ружья имеют свои наборы. Вместе с выбором
  игрок даёт предмету имя (суффикс) — прок + имя = «душа» предмета.
- **Только PvE** (решение 2026-07-06): проки НЕ срабатывают против игроков
  и НЕ триггерятся от действий игроков (проверка цели/источника на Player).
- Только базовые эпики, докачанные GA до легендарки; 5-е очко = 4100 убийств.
- Каждый прок — custom spell (spell_dbc) + AuraScript/хук в модуле;
  значения скейлятся от ilvl. ICD обязателен (иначе AoE-фарм ломает).
- Опорные коэффициенты: урон прока ~1.0 x ilvl; поглощение ~2.5 x ilvl;
  бурст-стат ~1.2 x ilvl на 8-10с; хил ~3.5 x ilvl.
- Предложение диапазона spell id: 108000-108099 (проверить занятость
  через dbc-investigator перед реализацией!).
- **Схема**: для подкласс-специфичных рядов в item_talent_def добавляется
  колонка `subclass SMALLINT NOT NULL DEFAULT -1` (-1 = любой), PK
  (pool,row,choice,subclass). Лукап: точное совпадение подкласса, затем
  фолбэк на -1. Миграция фазы 2.

## Идеи-расширения (копилка)

### Именное пробуждение (идея, записана 2026-07-06 — НЕ в работе)

Знаковые предметы (по конкретному item entry) получают УНИКАЛЬНЫЙ набор
легендарных талантов вместо общего меню пула. **Только ОРУЖИЕ (решение
2026-07-06)** - броня и щиты остаются на общем пуле. Пример: «Посох
Джордана» - свои 3 эксклюзивных прока со своими именами и лором.
Звук предмета играет только у полностью пробуждённого оружия В ОСНОВНОЙ
РУКЕ (двуручное её занимает; нюанс с дальнобойным слотом - решить при
разборе списка). Реализация ложится
в схему фазы 2: override по entry (отдельная таблица
`item_talent_named(item_entry, row, choice, ...)`), лукап: именной набор
-> подкласс -> пул.
Рабочий список кандидатов: PHASE2_EPIC_ITEMS.md (только оружие, 1392 шт.,
сортировка по возрастанию ilvl; колонки «Перк 1-3» и «Звук» заполняются
при разборе; звук - id из SoundEntries.dbc или свой файл через MPQ).

**Первый именной набор - 873 «Посох Джордана»** (тест; отсылка к Stone
of Jordan из Diablo 2: молния, мана, «валюта»; звук 5971
HumanMaleOfficialNPCGreetings; именные перки - НОВЫЕ кастомные, не
существующие игровые спеллы; от клиента только иконки/визуалы/звуки):

| Перк | Триггер | Эффект |
|---|---|---|
| Гнев Джордана | каст заклинания, 15%, ICD 8с | разряд молнии 1.2xilvl урона природой по цели (отсылка: +1-12 lightning damage у SoJ) |
| Цена Джордана | убийство, 20%, ICD 20с | чеканит 5xilvl меди владельцу (SoJ был валютой D2; на ilvl 40 - 2 серебра за прок) |
| Щедрость Джордана | пассив | +3xilvl к максимуму маны (отсылка: +mana у SoJ; на ilvl 40 - +120 маны) |
**Решение 2026-07-06: именные перки всегда одного качества** (x1.0,

### Персональные предметы с озвучкой (идея, записана 2026-07-06 — НЕ в работе)

Кастомный спелл-прок, который иногда срабатывает и ПРОИГРЫВАЕТ ЗВУК
(смех, реплика, любой аудиофайл) — предмет с «личностью», реагирующий
на события (крит, убийство, редкий idle). **Правило (2026-07-06): звук
надевания и проков активен ТОЛЬКО у полностью пробуждённого предмета
(выбраны все 5 рядов)** - голос предмета «просыпается» вместе с ним,
награда за полную прокачку. Технически два пути:
- **Без клиентского патча**: использовать существующие звуки клиента —
  тысячи готовых SoundEntries (смех НПЦ, реплики боссов); сервер шлёт
  `Player::PlayDirectSound(soundId)` владельцу или округе из хука прока.
  Подбор id — через dbc-investigator (SoundEntries.dbc).
- **Свой аудиофайл**: добавить запись в SoundEntries.dbc + файл в MPQ
  (клиентский патч, как для иконок) — тогда звук может быть любым
  (собственная запись, мем, голос).
Вместе с именованием предмета (5-й ряд) и уникальным проком получается
предмет-персонаж. Синергия с «Именным пробуждением» выше.

- Прок-синергии с системами: «души немезид» (прок усиливается по немезидам).
- Визуал прока: visual kit / существующие спелл-визуалы 3.3.5 на проке
  (подобрать через dbc-investigator).

## Открытые вопросы

- «Прямой в челюсть» (кастеты, прерывание каста) — проверить баланс в
  героиках: 8% с ICD 25с у танка-дуалвильда может закрыть слишком много
  кастов. Возможен ICD 45с.
- Стакаются ли одинаковые проки с двух предметов (оружие+броня одного
  пула не бывает, но A-плащ + A-роба возможны) - предлагаю общий ICD
  на игрока по spell id (естественно получается через ауру).
- «Фамильяр-фантом»: масштаб урона фантома и его видимость для других
  игроков; нужен ли отдельный DisplayID «призрачной» версии каждого
  фамильяра или один универсальный дух.
