# Фаза 2: эпическое ОРУЖИЕ под именное пробуждение

Решение 2026-07-06: именное пробуждение - ТОЛЬКО ОРУЖИЕ (броня и щиты
остаются на общем пуле проков). Все стоковые эпические оружия
(entry <= 60000), сортировка по ilvl (возр.). Колонки «Перк 1-3» -
кастомные именные перки (пустые = общий пул подкласса).

Колонка «Звук» - голос предмета: проигрывается при надевании и иногда
при проках, ТОЛЬКО когда оружие полностью пробуждено (все 5 рядов) И
находится в ОСНОВНОЙ РУКЕ (клиентский слот 16; двуручное тоже занимает
его). Нюанс: луки/ружья/арбалеты живут в отдельном слоте дальнего боя
(18) и под правило основной руки не попадают - решить при разборе.
Заполнять id из SoundEntries.dbc (подбор: .itemtalent sound <id>)
либо именем своего файла (MPQ-патч).

**Именные перки всегда ОДНОГО качества** (x1.0, без Отличных/Совершенных).
