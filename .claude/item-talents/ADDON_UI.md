# Item Talents — спецификация аддона (ItemTalentUI)

Статус: макет утверждён 2026-07-06 — **вертикальное дерево** (ретейл-стиль).
**v0.2 реализован 2026-07-06**: modules/mod-item-talents/ClientAddon/ItemTalentUI/
(в репозитории модуля). Оболочка TransmogUI: кнопка на окне персонажа
(-105/-41, рядом с кнопкой трансмога), панель 620x640 — слева 12 слотов
экипировки, справа дерево выбранного слота; /itu [слот]. Ctrl+ПКМ из v0.1
УБРАН (обработчики кликов биндятся к шаблону при загрузке XML — raw-замена
глобала не перехватывает). Отличия от исходной спеки: соединители L-образные
(не диагональные); описания талантов синтезируются на клиенте из effect-кода
+ value (desc_ru в OPT не передаётся); MAX_IMPLEMENTED_ROW = 2 продублирован
константой в Lua (поднять вместе с конфигом сервера). Ответы сервера прячутся
из чата фильтром CHAT_MSG_SYSTEM; автообновление 10 сек + UNIT_INVENTORY_CHANGED.
Родитель: DESIGN.md (§2 UI, §6 протокол).

## 1. Общая компоновка

Одно окно ~360x500, movable, позиция в SavedVariables, ESC закрывает.

```
┌─ Пробуждение снаряжения ──────────────┐
│ [икона 40px] Имя предмета (цвет кач.) │
│              эпик · ilvl 80 · ряды 4/5│
├───────────────────────────────────────┤
│  ЗАТОЧКА    ( )────(●)────( )         │
│                     │                 │
│  ЗАКАЛКА    ( )────( )────(●)         │
│                          ╱            │
│  ГРАВИРОВКА (●)────( )────( )         │
│              │                        │
│  НАСЫЩЕНИЕ  (◐)────(◐)────(◐) ← выбор │
│  ПРОБУЖДЕНИЕ(▢)────(▢)────(▢) закрыто │
├───────────────────────────────────────┤
│ Итог: +12 вын · крит 8 · износ -50%   │
│        [Сбросить ряд]   [Закрыть]     │
└───────────────────────────────────────┘
```

- Под шапкой — полоса опыта предмета: «Очки таланта: N» слева, «до следующего
  очка: X / Y убийств» справа, золотой прогресс-бар (обновляется при открытии
  панели и после каждого действия).
- 5 рядов x 3 узла. Подпись ряда слева — «ремесленный путь», утв. 2026-07-06
  (ЗАТОЧКА/ЗАКАЛКА/ГРАВИРОВКА/НАСЫЩЕНИЕ/ПРОБУЖДЕНИЕ),
  цвет подписи = цвет качества, которое открывает ряд (белый/зел/син/эпик/легенд).
- Узел: 44px, круглая рамка-оверлей поверх квадратной иконки (SetMask в 3.3.5
  нет — углы прячем под кольцом, фон панели однотонный тёмный).
- Соединители: линия от выбранного узла ряда N к выбранному узлу ряда N+1.
  Вертикаль/диагональ — тонкая текстура (диагональ через повёрнутый SetTexCoord,
  как маршруты на карте полётов). Непройденные сегменты — тусклый серый пунктир.

## 2. Состояния узла

| Состояние | Вид | Поведение |
|---|---|---|
| Выбран | золотое кольцо, иконка в цвете, лёгкое свечение (UI-ActionButton-Border, ADD) | тултип; ПКМ у мастера = сброс ряда |
| Доступен (ряд открыт, есть свободное очко) | зелёно-золотое кольцо, пульсация (AnimationGroup alpha 0.6-1.0) | клик = диалог подтверждения (тратит 1 очко) |
| Открыт, нет очков | приглушённое зелёное кольцо, БЕЗ пульсации | тултип/клик: «до очка: X убийств» |
| Не выбран (в ряду уже есть выбор) | серое кольцо, иконка desaturate, alpha 0.4 | тултип «в этом ряду выбрано: X» |
| Закрыт качеством | серое кольцо, замок поверх, desaturate | тултип «Требуется качество: Легендарный» |

Ряд 5 у предметов с базовым качеством ниже эпика — вечный замок: тултип
«Недоступен для этого предмета» (легендарка только для базовых эпиков).

Иконки талантов: маппинг effect -> путь к иконке хранится в аддоне статически
(11 effect-кодов, фаза 1). При желании позже — колонка icon в item_talent_def.

## 3. Взаимодействия

- **Открытие**: Ctrl+ПКМ по предмету (сумка/кукла) — raw-hook
  `ContainerFrameItemButton_OnClick` + `PaperDollItemSlotButton_OnClick`,
  при Ctrl+ПКМ блокируем стандартное действие. Без аддона — госсип у мастера.
- **Выбор**: клик по доступному узлу -> StaticPopup «Выбрать "Напор" (+16 к силе
  атаки)? Сбросить можно бесплатно у мастера оружия.» -> `.itemtalent choose`.
  Кнопка подтверждения неактивна, если сервер сказал nearMaster=0.
- **Сброс**: кнопка «Сбросить ряд» (активна только nearMaster=1) -> режим
  выбора ряда кликом, либо ПКМ по выбранному узлу.
- **После выбора**: сервер шлёт свежий info; узел вспыхивает (glow burst),
  линия дорисовывается, звук выучивания таланта; строка «Итог» обновляется.
- **После GA-апгрейда**: при первом открытии панели свежеоткрытый ряд
  пульсирует целиком + баннер «Открыт новый ряд!».

## 4. Протокол (поверх .itemtalent, ответы с префиксом ITALENT:)

Запрос аддона: `.itemtalent info <bag:slot | inv:slot>`
Ответ сервера (SYSTEM, построчно):
```
ITALENT:HDR:<guid>:<ilvl>:<quality>:<pool>:<rowsOpen>:<nearMaster>:<kills>:<freePts>:<nextNeed>
ITALENT:ROW:<row>:<chosen 0..3>
ITALENT:OPT:<row>:<choice>:<effect>:<value>:<name_ru>
...
ITALENT:END
```
Выбор: `.itemtalent choose <guid> <row> <choice>` -> сервер валидирует
(качество, ряд открыт, выбор пуст, есть свободное очко, nearMaster) ->
`ITALENT:OK` + новый info, либо `ITALENT:ERR:<код>`.
Сброс: `.itemtalent reset <guid> <row>` (только nearMaster).
Список: `.itemtalent list` -> строки
`ITALENT:ITEM:<invSlot+1>:<guid>:<pool>:<quality>:<kills>:<free>:<spent>:<имя>`
+ END. Аддон кэширует их по слоту и дописывает в тултип надетого предмета:
«Пробуждён: N из 5» (gold) / «Готов к пробуждению!» (green) / «Пробуждение:
убийств N» (grey). Открытие с предмета: Alt+ЛКМ по слоту на кукле
(hooksecurefunc на PaperDollItemSlotButton_OnModifiedClick — модифицированные
клики в 3.3.5 проходят через OnModifiedClick; Ctrl занят примеркой,
Shift - ссылкой).
Все значения value сервер считает сам (ceil(base+per_ilvl*ilvl)) — аддон
ничего не вычисляет, только рендерит.

## 5. Русский текст

ASCII '-' и ':' вместо тире (глифы 3.3.5), UTF-8. Названия/описания талантов
приходят с сервера из item_talent_def (name_ru/desc_ru с подставленным {N}).
