# Каталог перков — таблица (mod-item-talents)

Иконка перка указана каноничным именем файла из MPQ (в обратных кавычках
рядом с названием): полный путь `Interface\Icons\<Имя>.blp`. Клиент к
регистру нечувствителен; эти же имена прописаны в маппинге аддона
ItemTalentUI.

**Формула силы перка**: `база = ceil(коэф x ilvl)`, дальше каждая ступень
качества: `значение(q) = max(значение(q-1) + 1, ceil(база x множитель))` —
ступень ВСЕГДА даёт минимум +1, даже на малых базах (решение 2026-07-06).

Качество ролла: **Обычное** x1.0 (70%) / **Отличное** x1.25 (25%) /
**Совершенное** x1.5 (5%).

В колонках ilvl каждая ячейка — тройка значений **обычное / отличное / совершенное**.
Ориентиры: ilvl 20 = лоулевел, 60 = классика-энд, 120 = БК, 200 = Наксс, 264 = ЦЛК.
